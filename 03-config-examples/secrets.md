# Безопасное хранение ключей

Главное правило: **ключ не должен попасть в Git**. OpenCode умеет читать
ключ из переменной окружения по ссылке `{env:VAR}`, поэтому в
`opencode.json` хранится только имя переменной, а не значение.

## 1. Добавьте `.env` в `.gitignore`

В корне проекта создайте `.gitignore` (если его ещё нет) и добавьте:

```gitignore
.env
.env.local
*.key
```
