# Установка Node.js (Windows)

Node.js нужен, потому что через `npm` устанавливается OpenSpec (и один из
способов установки OpenCode). Рекомендуем LTS-версию.


1. Откройте [страницу загрузки Node.js](https://nodejs.org/) и скачайте **LTS**-версию для Windows.
2. Запустите установщик, оставьте настройки по умолчанию.
3. После установки откройте **новый** терминал (PowerShell или cmd) и проверьте:

```powershell
node --version   # ожидаем v22.x или v24.x (LTS)
npm --version
