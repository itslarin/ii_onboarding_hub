# Плагин `opencode-plugin-openspec` (опционально)

Плагин добавляет в OpenCode отдельного агента **`openspec-plan`** для
планирования и написания спек. Его ключевая особенность — права записи
только в `openspec/**`, `specs/**`, `project.md` и `AGENTS.md`, но **не в
код**. Это защищает от преждевременного кодинга во время планирования.

## Установка

Плагин не требует ручного `npm install`: достаточно добавить его имя в
массив `plugin` в `opencode.json`. OpenCode сам скачает и установит плагин
при следующем запуске[reference:10].

Откройте `opencode.json` (в корне проекта или `~/.config/opencode/opencode.json`)
и добавьте:

```json
{
  "$schema": "https://opencode.ai/config.json",
  "plugin": ["opencode-plugin-openspec"]
}
```

Если массив plugin уже есть — просто добавьте строку:

```json
"plugin": ["другой-плагин", "opencode-plugin-openspec"]
```

## Как пользоваться
- Откройте OpenSpec-проект в OpenCode (после openspec init).
- Плагин автоматически определит, что workspace — OpenSpec-проект.
- В селекторе агентов выберите openspec-plan (агент подсвечен цветом).
- Работайте над спеками и планом. Код при этом защищён от случайных
изменений.

## Когда плагин особенно полезен
- Команда хочет жёстко разделить «планирование» и «реализацию».
- В проекте несколько участников, и риск «AI сразу начал писать код»
критичен.
- Нужен явный режим «только спеки, код не трогаем».

## Проверка
- В opencode.json появился "opencode-plugin-openspec" в plugin
- После перезапуска OpenCode в селекторе агентов доступен openspec-plan
- При выборе openspec-plan код остаётся read-only, а openspec/** доступен для записи
