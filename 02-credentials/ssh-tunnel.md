Некоторые роутеры недоступны из РФ, либо сами блокируют трафик из РФ.
Если у вас есть сервер (в том числе виртуальный), размещенный за пределами РФ, возможен вариант работы с роутерами / эндпоинтами за счет организации SSH-туннеля.
Для организации туннеля необходимо выполнит на рабочей машине команду

```bash
ssh -N -D %port% %user%@%host
port - номер порта, который вы задействуете на СВОЕЙ рабочей машине
user - имя юзера на сервере
host - ip / hostname сервера
```

В случае успешного соединения сервер запросит пароль для указанного в команде пользователя, при успешном вводе терминал "повиснет", никаких выводов приглашений или информации не произойдет. Это будет означать, что туннель установлен.
